# ChainEye
链眼 (ChainEye) - 链上资产风险检测工具 链眼是一个为加密投资者设计的风险评估平台，通过 AVE Cloud Data API 实时数据，对代币进行全面分析，生成 0-100 分的健康评分。 核心功能： 评估 8 个风险维度：买卖税检测、流动性分析、代币年龄、价格波动性、交易量异常、持仓集中度、合约特性和综合评分。 设计理念： 融合《电锯人》的极简黑白风格与《JOJO》的夸张排版，采用玛奇玛的冷静语气。用户输入代币地址，选择链（BSC、ETH、Base、Solana），即可获得详细风险分析。 技术实现： 基于 React 19、Express 4 和 tRPC 11 构建，采用多因素加权评分算法，基于真实链上数据分析。
